# 标准条目库 v1

> 用途：教练判断的唯一依据来源。三层溯源，每条标层级、出处、局限、状态。
> 层1 可硬用；层2 用于定位、规格与立意架构判断；层3 是园所推导，必须标待校准，靠锚点片和试跑校正。

## 层1 · 通用剪辑工艺

### S1-01

**条文**：情绪优先：剪辑六条权重为情绪 51%、故事 23%、节奏 10%、视线 7%、二维平面 5%、三维空间 4%。

- 出处：Murch《In the Blink of an Eye》；parker.mov 的 Rule of Six 整理页
- 局限：权重是经验模型，不是测量结果；用于排序取舍，不用于打分。
- 状态：已采纳（可硬用）

### S1-02

**条文**：剪不下去时从下往上牺牲：先丢三维空间，再丢二维平面，最后才动情绪与故事。

- 出处：同上
- 局限：只适用于必须缩短的场景。园所片子常见问题是镜头太碎，不是太长。
- 状态：已采纳

### S1-03

**条文**：180° 轴线：同一场景内机位不要越过人物连线，否则左右关系翻转。

- 出处：连续性剪辑术语表；purrlearn 30° 规则页
- 局限：单机位跟拍片、快切群像片容易连犯；执行时按建立镜头先定关系。
- 状态：已采纳

### S1-04

**条文**：视线匹配：上一镜人物看向画外某方向，下一镜要接住这个方向的落点。

- 出处：同上
- 局限：需要拍摄时就有意图；事后剪辑只能补救不能创造。
- 状态：已采纳

### S1-05

**条文**：银幕方向一致：同一主体在同一段落里保持同一运动方向，左进左出。

- 出处：同上
- 局限：往返跑动题材（如骑车绕圈）天然违反，需靠建立镜头交代环境。
- 状态：已采纳

### S1-06

**条文**：动作中剪：在动作进行中切换，而不是等动作结束再切。

- 出处：同上
- 局限：要求前后镜有重叠动作；素材没拍到重叠就没法用。
- 状态：已采纳

### S1-07

**条文**：30° 规则：同一主体连续两镜，机位角度或景别至少变化 30°，否则看起来像画面跳了一下。

- 出处：purrlearn 连续性剪辑页
- 局限：数值是经验门槛；孩子乱动的片子更难判断，可放宽到明显景别差。
- 状态：已采纳

### S1-08

**条文**：细节一致：服装、道具、时间光线、背景陈设前后不能跳。

- 出处：连续性剪辑术语表
- 局限：跨天素材最容易犯；发现跳了就删掉其中一段，不要靠调色硬圆。
- 状态：已采纳

### S1-09

**条文**：先给建立镜头：一个段落开始，先用一个能交代这是哪儿、有谁的镜头。

- 出处：同上
- 局限：短片只有 15 秒时可能挤不进建立镜头，可用字幕或片头代替。
- 状态：已采纳

### S1-10

**条文**：硬切是默认，占比八成以上；叠化不是常态。

- 出处：转场类型页；叠化帧数建议页
- 局限：八成是行业惯例，不是硬指标；园所片子可到九成。
- 状态：已采纳

### S1-11

**条文**：叠化只用于表时间流逝或情绪柔和，长度 6—12 帧（0.2—0.4 秒）；超过 1 秒就是拖沓。

- 出处：叠化 6—12 帧与一套语法出处：melliusai 转场页
- 局限：帧数区间来自单一教程建议，社区也有 0.3 秒与 1 秒两种用法；我们采用短的那一档，理由是与硬切为主的语法一致。
- 状态：已采纳（帧数区间标教程建议）

### S1-12

**条文**：说不出这个转场在表达什么，就改用硬切。

- 出处：flashboards 转场教学页
- 局限：判据本身是主观的，靠能不能说出理由来裁，属于可执行的折中。
- 状态：已采纳

### S1-13

**条文**：一个项目只用一套转场语法，不要一场叠化一场闪白一场擦除。

- 出处：melliusai 转场页
- 局限：无。
- 状态：已采纳

### S1-14

**条文**：闪白、闪黑这类强转场，全片不超过 3 次。

- 出处：转场类型页
- 局限：次数是惯例值；幼儿片子建议 0—1 次。
- 状态：已采纳

### S1-15

**条文**：先修硬切处的衔接，再谈加转场。

- 出处：转场教学页
- 局限：属于工作顺序建议，非测量标准。
- 状态：已采纳

### S1-16

**条文**：声音是剪得顺不顺的第一嫌疑：去掉音频后，观众基本察觉不到剪接点。

- 出处：Edit Blindness 研究与 match-action 去音频实验
- 局限：结论来自实验情境，幼儿片子声音更杂，效果可能打折；但方向成立。
- 状态：已采纳

### S1-17

**条文**：单镜头信息量比时长更关键：镜头短不是问题，一个镜头里没信息才是问题。

- 出处：社区与行业共识，无可引来源
- 局限：无权威文献支撑，属经验判断；遇到争议按此执行但不作为唯一依据。
- 状态：暂定（无出处）

## 层2 · 受众、定位与立意架构

### S2-01

**条文**：家长关心排序：生活习惯与文明礼貌 90.7%、人际交往与性格 81.3%、身体发育 78.9%、自信开朗 72.5%、学习品质 71.5%；知识类 43.0%、艺术特长 33.2%。

- 出处：网络转载的家长关注点问卷（样本与抽样方式未公开）
- 局限：单一问卷来源，样本量与地域未说明；用于排序参照，不作绝对结论。
- 状态：已采纳（标注样本局限）

### S2-02

**条文**：首选幼儿真实游戏生活片段，减少表演式拍摄。

- 出处：线上家长问卷与同源分析
- 局限：偏好类结论，随园所与家长群体变化；每学期可复盘一次。
- 状态：已采纳

### S2-03

**条文**：常规短片 15—90 秒；横版 16:9、1920×1080。

- 出处：赛事／报送征集要求（15—90 秒、1920×1080、净版）
- 局限：属报送口径，不等于家长群观看的最佳时长；家长群短片可更短。
- 状态：已采纳（区分报送与日常）

### S2-04

**条文**：报送类须交无字幕、无音乐、无包装、不压缩、带现场声的净版。

- 出处：报送征集通知
- 局限：各地要求不同，以对方最新通知为准。
- 状态：已采纳（时效以官方为准）

### S2-05

**条文**：部分报送要求开头有标题、结尾有落款。

- 出处：地方报送通知
- 局限：同上，属地方口径。
- 状态：已采纳（时效以官方为准）

### S2-06

**条文**：家长实际只感知四件事：稳不稳、清不清、乱不乱、有没有我孩子。

- 出处：家长问卷与分析稿综合，属归纳而非问卷原题
- 局限：归纳性结论，无直接问卷题项支撑；用于解释为什么工艺重要，不作评分项。
- 状态：暂定（归纳）

### S2-07

**条文**：一条片子先立一条主张：给谁看、想让家长看完记住什么；主张说不清时先回立意，不先动工艺细节。

- 出处：园所实践推导＋短视频内容判断常识归纳
- 局限：日常群像片从轻，一条主张即可，不要求广告片式强创意；主张是否成立需结合实际片例验证。
- 状态：暂定（归纳）

### S2-08

**条文**：开场三秒内交代这是哪儿、有谁、什么活动；观众看不懂开场就容易划走。建立镜头的连续性用法见 S1-09，本条从观众能不能看懂判断。

- 出处：园所实践推导＋短视频内容判断常识归纳
- 局限：15 秒以内极短片可由字幕或片头代替画面交代；三秒是经验值，非测量标准。
- 状态：暂定（归纳）

### S2-09

**条文**：过程围绕一条主线走，不做活动罗列；留下的镜头服务同一件事。现场一条动线的拍摄要求见 S3-07，本条是剪辑组织上的内容主线。

- 出处：园所实践推导＋短视频内容判断常识归纳
- 局限：集体活动素材多线并行时，允许一段落一条线，不强求全片单线索。
- 状态：暂定（归纳）

### S2-10

**条文**：结尾有落点，不半空停住；开场点出的事结尾有收束，高光可在结尾回扣一次。幼儿场景落点观察见 S3-09。

- 出处：园所实践推导＋短视频内容判断常识归纳
- 局限：家长群轻量短片是否必须落点，需按实际反馈验证；与 S3-09 互挂，不重复计分。
- 状态：暂定（归纳）

### S2-11

**条文**：孩子反应、现场金句、完整动作是可记住的瞬间，要留住并放大；被空镜、背影、旁白压住，是取舍上的缺口。

- 出处：园所实践推导＋短视频内容判断常识归纳
- 局限：记忆点判断受家长偏好影响，需用本班锚点片校准；不要求每条片都设计刻意高光。
- 状态：暂定（归纳）

### S2-12

**条文**：与主张无关的素材再好看也让位；取舍不明排在工艺问题前面查（归因顺序：立意没想清 → 取舍不明 → 工艺不熟）。

- 出处：园所实践推导＋短视频内容判断常识归纳
- 局限：取舍是优先级判断，不是素材淘汰清单；现场素材不足时另转拍摄侧补拍，不靠后期硬救。
- 状态：暂定（归纳）

### S2-13

**条文**：镜长随情绪张弛有长短起伏，不全程等长；长短搭配的剪映操作见 J44，单镜信息量判据见 S1-17。

- 出处：园所实践推导＋短视频内容判断常识归纳
- 局限：节拍与情绪曲线无量化标准，属经验判断；新手先把镜头剪干净、顺序排对，节奏搭配后练。
- 状态：暂定（归纳）

## 层3 · 幼儿场景专属工艺

### S3-01

**条文**：机位降到孩子视线高度，蹲下或贴地拍。

- 出处：园所实践推导
- 局限：无权威文献；成人高度俯拍会让孩子显得渺小，是与家长偏好相关的推论，需用锚点片验证。
- 状态：待校准

### S3-02

**条文**：固定机位优先，手持乱晃是硬伤。

- 出处：园所实践推导＋防抖功能局限（防抖会裁画面）
- 局限：跟拍题材（跑跳、骑车）难以固定机位，需按题材区分。
- 状态：待校准

### S3-03

**条文**：每条素材比计划时长多拍 8—10 秒，剪辑才有余量。

- 出处：园所实践推导
- 局限：孩子状态不可控，多拍是唯一低成本的保险；具体秒数为经验值。
- 状态：待校准

### S3-04

**条文**：避逆光，不让孩子站在窗前或太阳正对面。

- 出处：拍摄常识＋园所实践
- 局限：室内窗边活动常见，改机位比后期拉曝光有效。
- 状态：待校准

### S3-05

**条文**：不喊看镜头、笑一个：孩子一听指令就表演，真实感立刻没了。

- 出处：家长偏好（反表演式）＋园所实践
- 局限：与活动记录场景冲突时（如集体合影）可例外。
- 状态：待校准

### S3-06

**条文**：保留现场声，不要全片盖音乐；底乐不得盖住孩子说话。

- 出处：声音权重研究＋园所实践
- 局限：报送净版要求带现场声，与此一致；商业化短片另议。
- 状态：待校准（方向有支撑）

### S3-07

**条文**：一条片子尽量走一条动线，不要满场跳。

- 出处：园所实践推导
- 局限：集体活动天然多动线，需按题材降级为一段一动线。
- 状态：待校准

### S3-08

**条文**：每个镜头都要有信息；人均可辨认露脸要有保障，不能一堆镜头都是一闪而过。

- 出处：群像片经验观察（易出现一闪而过、认不出人的镜头）＋家长有没有我孩子的偏好
- 局限：人均露脸没有量化标准，园所可自定（如每人至少 1 个可辨认镜头）。
- 状态：待校准

### S3-09

**条文**：结尾要有落点：一个收束镜头或一句落款，不要停在半空。

- 出处：经验观察（结尾无落点的常见问题）＋园所实践
- 局限：家长群短视频是否必须落点，需按实际反馈验证。
- 状态：待校准

### S3-10

**条文**：集体活动要有集体身份交代：谁在场、哪个班、什么活动。

- 出处：实践归纳：记录人与记录事的区分、名单核对
- 局限：早期记录结论未逐条复核，仅保留洞察；不作为标准条文硬用。
- 状态：待校准（来源需复核）

### S3-11

**条文**：出问题先查拍摄、再查剪辑。剪辑救不了没拍到的画面。

- 出处：园所实践推导＋抽帧实测（手持跟拍片难以靠算法自动切分）
- 局限：归因顺序是工作方法，不是评价标准。
- 状态：待校准

### S3-12

**条文**：全片只用一套字体，字幕样式改好一条后套到所有字幕。

- 出处：早期评审表版式维度
- 局限：可数，但不判质量：字体统一了也未必好看，只作硬性下限检查。
- 状态：待校准

### S3-13

**条文**：字幕固定在画面底部同一高度，一行不超过 12—14 字，不压主体、不贴画面下沿。

- 出处：同上（早期评审表版式维度）；行字数与底部安全区为社区通行做法
- 局限：12 字是经验值，字号大时可到 10 字；以手机上看清为准。
- 状态：待校准

### S3-14

**条文**：特写（孩子表情、手部动作）要有占比，全片不能只有全景中景；参考下限 20%，做得好的片子常在 40% 以上。

- 出处：同上（早期评审表画面维度，特写占比 ≥40% 原为满分档描述）
- 局限：百分比属园所推导，无外部出处；特写多不等于好，要看是不是有效特写。
- 状态：待校准

### S3-15

**条文**：全片转场种类不超过 2 种，且以硬切为主。

- 出处：同上（早期评审表克制维度）；与 S1-10 硬切默认为同向
- 局限：可数指标；两种以上不算罪，是新手最容易堆的地方。
- 状态：待校准

### S3-16

**条文**：片头与片尾要统一：片头不超过 3 秒、不放动画，片尾用同一套落版样式。

- 出处：同上（早期评审表版式维度）＋报送口径（S2-05 结尾落款）
- 局限：片头时长是园所自定；报送类与家长群类可以不同。
- 状态：待校准

### S3-17

**条文**：响度不套广电播出标准（GY/T 375—2023 的 -24 LKFS 那类），家长群片子按听得清、不爆音、段间不忽大忽小判。

- 出处：曾参照 GY/T 375—2023 广电响度标准；微信压缩链路下响度与播出标准存在明显差距
- 局限：广电标准服务于电视播出链路，园所片子走微信压缩，链路不同，不能直接套。
- 状态：待校准

## 使用规矩

1. 一条建议挂不上具体编号，就是没依据，不许说成标准。
2. 层3 引用时必须带待校准三个字，不许说成权威结论。
3. 条目可改，但只能追加新状态，不覆盖旧记录。
4. 出处时效性：政策与规格类以官方最新为准。
